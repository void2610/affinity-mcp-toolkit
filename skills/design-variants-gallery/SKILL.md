# 案出しと反復

## 原則

- **1 軸ずつ振る**。配色を決めてから背景、背景を決めてから光、のように、決まった要素は固定して残りを振る。
- **同じ土台で描く**。案は必ず現在の構図・サイズの上に描画する (ロゴ案ならヒーロー上段の実寸、配色案なら全体)。単体で見せると比較にならない。
- **CSS 変数に寄せてから振る**。色・光の強さ・格子の濃さを `:root` の変数にしておけば、案は変数ブロックの差し替えだけで作れる。案ごとの変数値は JSON に残す。
- **参考は実物を見る**。「有名どころを参考に」と言われたら README や公式サイトの画像を実際に取得し、寸法と構成を測ってから真似る。線アイコン風か塗りの幾何か、器の有無、色数といった文法を読み取り、同じ文法で作る。
- **ユーザーの否定は文法の否定**。「ダサい」「同じに見える」は個別案ではなく作り方 (器、線、プリミティブの積み方) への否定として受け取り、作り方を変える。禁止された要素 (丸、器、プリミティブ等) は以後の全案で守る。
- **勝手に変えない**。指示にない幅・サイズ・内容の変更はしない。必要なら理由を述べて提案に留める。

## ギャラリーの作り方

1. 各案を同じ寸法で PNG に描画する (`html-to-png-parts`)。比較用は 0.5 倍で十分。
2. 1 ページの HTML に `<figure>` として並べ、案名と一言説明 (意図) を添える。画像は data URI で埋め込み、ページは 16MB 以内にする。
3. Artifact として公開し、同じ URL を更新し続ける。「全部並べて」と言われたら系統ごとに節を分けて 1 ページにまとめる。
4. 選ばれた案は即座に本体へ反映し、決定経緯 (何案から何を選んだか) を README などに記録する。

## 反復のときの報告

- 変えた点、変えなかった点、トレードオフ (例: 間隔統一と対称は両立しない) を短く書く。
- 本画像はファイルとして送る (縮小プレビューだけで済ませない)。
