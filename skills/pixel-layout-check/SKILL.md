# 画素でレイアウトを検証する

座標計算だけで「揃っている」と言わない。書き出し画像を測ってから報告する。

## コマンド

```bash
scripts/measure.sh body <part.png>            # 影を除いた本体の境界 (alpha 85% しきい値)
scripts/measure.sh border <part.png> <rgb>    # 指定色の枠線の境界 (例: "rgb(255,213,79)")
scripts/measure.sh extent <img.png> <y0> <h>  # 帯 y0..y0+h の可視範囲 (左端 x と幅)
scripts/measure.sh corners <img.png>          # 四隅と各辺中央の画素色
scripts/measure.sh zoom <img.png> <x> <y> <w> <h> [scale] <out.png>  # 拡大切り出し
```

## 手順

1. **本体境界**: 影やグロー込みで切り出した PNG は、`body` で本体の左上オフセットと実寸を測る。配置座標はこのオフセットで補正する。
2. **余白**: 上段・下段など帯ごとに `extent` を取り、左右の余白を比べる。グローは可視範囲に入るので、光る要素の余白はグロー込みで判断する。
3. **端**: `corners` で四隅が背景色か確認する。白や透明が出たら描画側の margin/padding が原因。
4. **繰り返しパターン**: 格子や十字が端で半分に切れていないか、端の帯を `zoom` で見る。切れるなら位相をずらす。
5. **接続部**: 線の合流点・矢印の先端・バッジの中央揃えは `zoom` で 2〜3 倍にして見る。1024px のプレビューでは判断できない。

## 判断基準

- 「対称」は中心座標の差で示す。要素の高さが違う場合、中央要素の中心から上下の中心が等距離なら対称。間隔統一と対称は同時に成立しないことがあるので、どちらを優先するか明示する。
- 余白は「本体の枠」ではなく「見える範囲」で揃える。
- 修正のたびに測り直し、報告には測った数値 (左右余白、中心 y、隙間) を添える。
